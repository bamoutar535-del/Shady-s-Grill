# Shady’s Grill – Site Vitrine Bilingue (FR/EN)

## 📌 Description
Ce projet est un site vitrine bilingue (Français/Anglais) pour **Shady’s Grill**, restaurant familial situé sur la Route de l’Aéroport à Dakar (en face CBAO, 50 m après la station Shell).  
Il est conçu pour accueillir les visiteurs locaux et internationaux, avec un menu varié et des boissons maison.

## ✨ Fonctionnalités
- Page unique responsive (`index.html`)
- Menu de navigation clair (Présentation, Menu, Avis, Localisation, Réservation)
- Galerie d’images (`assets/images/`)
- Carte Google Maps intégrée (localisation Shady’s Grill)
- Formulaire de réservation + lien WhatsApp
- Design moderne avec CSS (`css/style.css`)
- Widget Google Translate (FR ↔ EN)
